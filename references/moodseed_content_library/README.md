# Moodseed 内容库文件说明

建议直接将整个文件夹交给开发 Agent。

文件包括：

1. `01_PLANTS.md`  
   三株首版植物、情绪主题、CBT 对应关系、植物卡文案。

2. `02_EMOTIONS.md`  
   28 个标准情绪标签及 AI 标签规则。

3. `03_CBT_PATTERNS_AND_INTERVENTIONS.md`  
   12 个 CBT 常见认知模式、说明、调整方法、反思问题。

4. `04_EMOTION_PLANT_MAPPING.md`  
   情绪 → CBT → 植物对应关系，以及植物不可随单条情绪切换的规则。

5. `05_AI_SAFETY_AND_OUTPUT.md`  
   DeepSeek 输出结构、安全边界、诊断限制、高风险内容处理原则。

6. `06_FORTUNE_CARD.md`  
   120 条幸运语、24 个幸运色、幸运食物、建议/避免池、每日生成和 UI 展示规则。

7. `07_AGENT_PROMPT.md`  
   可直接发送给开发 Agent 的实现任务说明。

推荐：

> 将整个文件夹放进代码仓库中的 `/docs/moodseed-content/`，然后让 Agent 先读取 `07_AGENT_PROMPT.md`。
