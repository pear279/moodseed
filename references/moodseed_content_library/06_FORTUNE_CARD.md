# Moodseed 幸运卡内容库

## 1. 产品结构

每日签到后展示一张幸运卡。

参考现有 UI 结构，保留：

- 幸运颜色
- 幸运数字
- 幸运食物
- 中间每日幸运语
- 底部「建议」
- 底部「避免」

顶部删除第二行说明文字，例如：

原版：

> 橙色  
> 幸运色

调整为：

> 橙色

原版：

> 3、4  
> 幸运数字

调整为：

> 3、4

原版：

> 香蕉  
> 幸运食物

调整为：

> 香蕉

保持图片参考中的整体结构，不需要第二行灰色功能说明文字。

# 3. 每日生成规则

每天根据：

`date + anonymous_user_id`

生成稳定随机 Seed。

要求：

- 同一用户同一天刷新页面，幸运卡内容保持一致。
- 第二天重新生成。
- 不调用 AI 实时生成幸运卡。
- 不产生额外模型 Token 成本。

每日选择：

- 幸运色：1 个
- 幸运数字：1～9 中随机 2 个不重复数字
- 幸运食物：1 个
- 幸运语：1 条
- 建议：2 条且不重复
- 避免：2 条且不重复

---

# 4. 幸运语内容原则

幸运语定位：

> 轻积极、轻提醒、轻仪式感。

避免：

- “你今天一定会遇到贵人。”
- “今天有重大风险。”
- “今天一定会发财。”
- “今天不适合出门。”
- 任何具有确定性预测或制造焦虑的内容。

# 10. UI 展示规则

推荐结构：

```text
┌─────────────────────────┐
│ 🟩 鼠尾草绿 │ 3、7 │ 🍌 香蕉 │
└─────────────────────────┘

┌─────────────────────────┐
│ 今天可能更容易在意还没发生的事情，│
│ 可以把注意力放回眼前这一小步。    │
└─────────────────────────┘

┌──────────┐  ┌──────────┐
│ 建议      │  │ 避免      │
│ 散步 整理 │  │ 熬夜 硬撑 │
└──────────┘  └──────────┘
```

要求：

- 顶部三个元素保持横向排列。
- 删除「幸运色 / 幸运数字 / 幸运食物」第二行说明文字。
- 中间只展示一条幸运语。
- 底部「建议」「避免」各最多 2 项。
- 文案保持短。
- 不增加额外解释。
